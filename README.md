# Microsoft 365 Admin Runbooks

## What This Is

Step-by-step admin guides (runbooks) for the Microsoft 365 tasks I
practiced in the free Developer Tenant: Exchange Online, Teams, and
SharePoint. Each runbook is written so someone else could follow it and
get the same result.

## Tools Used

- Microsoft 365 Developer Tenant (Instant Sandbox)
- Exchange admin center
- Teams admin center (admin.teams.microsoft.com)
- SharePoint admin center

## Runbooks

- **Exchange mail flow rule** — configure a mail flow (transport) rule
  and a shared mailbox in Exchange Online
- **Teams policy** — create a Teams policy in the Teams admin center
- **SharePoint site** — create a SharePoint site for the team

## Status

In progress — building in the M365 Developer Tenant. Each runbook will be
written up here with screenshots as it's completed.

## Why It Matters

A runbook turns one-off practice into repeatable process. In a real IT
role, the next person to do the task should be able to follow the guide
and get it right.
